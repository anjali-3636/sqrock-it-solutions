
# Sqrock IT Solutions - Java Projects

## About the Project

This repository contains the Java projects completed as part of the Java Development tasks given by Sqrock IT Solutions.

## Projects

### 1. Online Quiz
A simple Java program that allows the user to answer quiz questions and displays the result.

### 2. Online Banking
A simple Java program that performs basic banking operations such as checking balance, depositing money, and withdrawing money.

### 3. Job Portal
A simple Java program that allows users to view and manage job-related information such as job details, skills, salary, and job type.

## Technologies Used

- Java
- VS Code

## Concepts Used

- Variables
- Data Types
- If-Else
- Loops
- Methods
- Classes and Objects
- Arrays / ArrayList
- User Input using Scanner

## Database

No database was used in these projects.

## How to Run

1. Install Java JDK.
2. Open the `.java` file in VS Code.
3. Compile the program.
4. Run the program.

Example:
bash
javac JobPortal.java
java JobPortal
